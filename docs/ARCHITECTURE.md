## 🎯 ЦЕЛЬ АРХИТЕКТУРЫ

**Построить B2B-платформу с полным DevOps-циклом:**

- Разработка (Python + FastAPI)
- Контейнеризация (Docker)
- Оркестрация (Kubernetes)
- Инфраструктура как код (Terraform + Ansible)
- CI/CD (GitHub Actions + ArgoCD)
- Observability (Prometheus + Grafana + Loki)
- SRE-практики (SLI/SLO, error budget)

**К дню 100:** production-grade архитектура.

## 🔄 ПОТОК ДАННЫХ

### Пример: запрос пользователя

```
1. Client → HTTPS request на lab.wallstackaudio.com
2. Nginx → принимает, терминирует SSL, проксирует на :8000
3. FastAPI → обрабатывает, делает запрос в PostgreSQL
4. PostgreSQL → возвращает данные
5. FastAPI → формирует JSON-ответ
6. Nginx → отдаёт клиенту
```

### Пример: deployment

```
1. Developer → git push в main
2. GitHub Actions → запускает CI (тесты, build)
3. Образ → пушится в GHCR
4. ArgoCD → видит новый образ, обновляет K8s
5. K8s → rolling update pod'ов
6. Monitoring → метрики в Prometheus, дашборд в Grafana
```
